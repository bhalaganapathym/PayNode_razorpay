# Merchant UI (PayNode)

The Merchant UI is hosted inside the unified PayNode React Application (`paynode/frontend/src/components/MerchantCatalog.tsx`).

### Features:
- Drag-and-drop CSV catalog upload and bulk ingestion.
- Instant search and category filtering.
- Dynamic Add/Edit/Delete product modal.
- Live stock status badges and ₹1,000 guardrail indicators.
- Direct synchronization with Supabase and FastMCP server.
