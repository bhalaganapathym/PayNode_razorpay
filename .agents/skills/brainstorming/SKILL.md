# Brainstorming & Ideation Skill

Structured methodology for exploring problem spaces, generating creative alternatives, and evaluating trade-offs for novel technical designs.

## Methodology
1. **First-Principles Framing**: Define the fundamental user problem before evaluating solutions.
2. **Divergent Exploration**: Brainstorm 3+ distinct approaches (e.g. lightweight vs comprehensive, centralized vs distributed).
3. **Trade-off Matrix**: Compare latency, complexity, cost, security, and developer ergonomics.
4. **Convergence**: Select the optimal path and establish measurable success criteria.
