# Frontend Stunner Skill

Techniques for creating visually breathtaking, immersive, and ultra-smooth modern web applications that deliver an immediate WOW factor.

## Visual Design Pillars
1. **Curated Dark Mode Palettes**: Deep slate/space background (`#0B0F19` or `#0F172A`) paired with electric violet (`#7C3AED`), neon pink (`#EC4899`), and vivid cyan (`#06B6D4`).
2. **Glassmorphism**: `backdrop-blur-xl`, semi-transparent frosted panels (`rgba(17, 24, 39, 0.7)`), and subtle 1px border glows (`border-white/10`).
3. **Framer Motion Dynamics**: Smooth staggered entrance animations, fluid layout transitions (`layoutId`), and micro-interactions on hover and click.
4. **Data Visualization**: Customized Recharts charts with glowing fills, gradient curves, and dark tooltips.
